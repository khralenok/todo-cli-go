# Todo CLI Go

todo-cli-go is command line interface for for creating and managing your list of tasks. It's my first application written with go with main focus on learning srtucts, pointers and basic language syntax.

## Features

List of available features is accessible right from staring screen, and offer all core Todo app features.

### Add items

You can simply add new item. By default it creates with "unsolved" status.

### Change item status

Once you done with a task, you can mark it as solved.

### Remove items

Once you don't need the task, you can simply remove it.

### Save your list locally

Once you run the app, it check if list already exist and if it doesn't, app will automatically create it, and then will save updates to it after each step.

## How to use

Since it's study project, I suppose best option is just run it through command line in you code editor with next command:

```
go run .
```

but you free to build it and run as standalone command line app.

## Tech Stack

This project is written with plain Go and it's standart libraries.
